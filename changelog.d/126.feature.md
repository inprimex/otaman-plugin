`otaman doctor` now reports when a sibling checkout on this machine is behind
its own remote.

Agents are directed to read sibling repositories to understand their
interfaces. A checkout quietly behind its remote makes that reading wrong, and
until now nothing on the machine said so — the first sign was continuous
integration disagreeing with work that looked correct locally.

Each repository is reported separately, with the number of commits it is
behind and the command to bring it level. The comparison uses the repository's
own default branch, asked of the remote rather than assumed, so a repository
that does not use `main` is still reported correctly.

The comparison is offline and never fetches. Every verdict therefore states
how old the local view of the remote is, and a view too old to answer the
question is reported as not checked rather than as current.
