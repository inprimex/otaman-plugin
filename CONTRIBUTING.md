## How to sign off

For every commit, include a sign-off line at the bottom of the commit message:

    Signed-off-by: Your Name <your.email@example.com>

You can add this automatically with `git commit -s`.

The sign-off acknowledges you agree to the terms above and the Developer
Certificate of Origin: https://developercertificate.org/

## Issue and PR etiquette

- Search existing issues before opening a new one.
- For non-trivial changes, open an issue to discuss before sending a PR.
- Keep PRs focused — one concern per PR makes review tractable.
- Include tests for behavioural changes.
- Run the test suite locally before submitting.

## Code of conduct

Be respectful. Disagreements about technical decisions are welcome; personal
attacks are not. The maintainers will moderate accordingly.

## Questions

Open a GitHub Discussion or issue. Response time is best-effort.
