Security gate runs now produce a result record for the review flow.

It sets out what each layer of checks found, any suppressions that lack the
required justification, and any case where the automated tools and the
language-model reviewer disagreed. Where they disagree, the tools decide and
the disagreement is recorded for a person to settle — it is never quietly
reconciled.

Whether a result blocks is worked out in one shared place rather than
separately by the part that writes the record and the part that displays it,
so the two cannot drift into contradicting each other.

The summary names the failing layers and the exact location of each
unjustified suppression, rather than reporting a count someone then has to
go hunting through.
