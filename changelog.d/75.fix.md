Installing this package now carries its attribution notice again.

`NOTICE` — which holds the copyright attribution, the SPDX identifier
and the commercial/CLA pointers — was left out of the built wheel. The
packaging metadata named only `LICENSE`, and naming any file at all
replaces the default rule that would have included both. Before the
licence text and the attribution lived in one file, so an install
carried both; splitting them dropped the attribution without anything
reporting a problem.
