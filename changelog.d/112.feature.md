Specification critiques now record which model route they ran on, alongside
their token and cost figures.

Nothing was recording this anywhere, so cost reporting could not distinguish
a critique run on one backend from the same critique run on another. The
dispatcher owns the invocation and its tokens, so it records them.

Where an agent declares no route, the record says so rather than naming a
stand-in — otherwise a default would be indistinguishable from a route that
happens to carry that name. Where routing configuration is missing or
unreadable, the cost is still recorded without a route, since losing the
figures entirely would be the worse outcome.
