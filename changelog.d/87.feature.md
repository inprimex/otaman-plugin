Generated agent instructions now require an agent to say so before it
stops for a human decision.

A session waiting on an unanswered prompt is still running and still
claims to be working. It cannot time out, resolve itself, or be reached
by a message — so it is found only when someone happens to look at it.
Three such stalls cost about eleven hours of delivery in a single day,
and one later ran for sixty-two hours holding a verification step.

Agents are now told to send a `decision-required` message naming the
decision, what it blocks, and what would unblock it, before blocking —
turning an invisible stall into an item in someone's queue. The existing
halted-session report is described as the net that catches a missed
one, not an alternative to sending it.
