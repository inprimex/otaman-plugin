Generated agent instructions no longer promise when a completion tick lands.

Filing a task complete against a specifications repository you do not own
now says plainly that the durable tick is deferred to that repository's
owner and that the file on disk is unchanged. It names no schedule,
because there is none to name.

The owner is read from the project configuration rather than assumed, so a
program keeping its specifications elsewhere is pointed at the right agent.
An agent that owns the repository is instead told the tick is its own work
and nobody else will do it.
