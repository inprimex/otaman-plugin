Changes to the fleet's coordination repository are now checked on the server,
not only on the machine that makes them.

The existing guard runs as a local hook, so it never sees a change merged
through a pull request. Three checks now run in continuous integration where
nothing can be skipped: the same structural-key comparison the local guard
uses, validation of the platform configuration against the shared schema, and
a lint of every knowledge-pack entry.

Each check reports "could not determine" separately from "found a problem",
and refuses in both cases. A server check that passes what it could not read
certifies nothing, which is the opposite of the local guard's default — there,
refusing on an unreadable file would block the change that repairs it.
