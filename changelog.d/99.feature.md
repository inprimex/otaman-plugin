Security gate workflows are now generated per repository from its recorded
technologies and the project's gate configuration.

The tools a repository runs come from configuration alone; the generator
only resolves and renders them. A technology the mapping does not
recognise is reported rather than quietly ignored, so a gap in the
vocabulary cannot pass for a repository that simply has nothing to scan.

A repository with no gate configuration gets no workflow at all, rather
than one that passes without checking anything. A repository that opted out
is reported as opted out, which is a different thing from never having been
configured. The advisory deep-scan layer is left out entirely unless asked
for, since a slow job nobody wanted teaches people to ignore the ones that
matter.
