# Tier B — Simple Estimation Template (5-8 pages)

**Method**: Analogous estimation with adjustment factors.
**Accuracy**: ±30-40%

## Sections

1. **Executive Summary** (1 page)
2. **Requirements Summary** (1 page) — functional, technical, constraints
3. **Reference Project Comparison** (2 pages) — 2-3 similar projects from benchmarks, adjustment factors (+10-20% per scope addition, +15-25% novel tech, -10-20% experienced team, +20-40% compliance), lessons learned
4. **Effort Estimate by Phase** (2 pages) — phase breakdown, team composition, duration/cost per phase
5. **Key Assumptions & Risks** (1 page) — top 5 assumptions, top 3 risks, contingency 25-30%
6. **Technology Stack Overview** (1 page)
7. **Next Steps** (1/2 page)

Use `search_benchmarks` MCP tool to find reference projects. Apply adjustment factors documented in `estimation-benchmarks.yaml`.
