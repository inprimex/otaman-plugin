`otaman doctor` and the session view now distinguish a session that is
frozen from one that has died.

A session waiting on a prompt nobody answered is still running and still
claims to be working, so a liveness check reported it as fine and the
staleness rule reported it as stale — which reads as "it died". Neither
was true, and the difference decides what happens next: a dead session
needs nothing, a frozen one needs someone to answer a prompt.

Such a session is now reported as halted, naming the agent, how long it
has been silent, and the likely cause. A session that is merely missing
its heartbeat is not reported this way, since its silence already has a
different and separately reported explanation.
