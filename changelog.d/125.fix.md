The post-commit review hook now notifies the observers a program declares, and
sends nothing when a program declares none.

It had always addressed the human directly while telling them that "observers
matching these triggers should review this commit" — so on a program with no
observers configured, which is every program, each commit added a message to
the human's queue that named no one able to act on it.

Commits are also now attributed to the owner of the repository they happened
in. Attribution previously came from a single file shared across the whole
installation, so every repository's commits were credited to whichever agent
last wrote that file.
