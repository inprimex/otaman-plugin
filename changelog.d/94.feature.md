The agent that owns a specifications repository now applies its pending
completion ticks when its session starts.

Reporting a task complete files a record straight away, but writing it into
the task list is something only that repository's owner can do in a way that
lasts. Until now nothing prompted them, so records could sit unapplied for
weeks while progress views quietly under-reported.

The drain reports what it did in terms that stay apart: ticks applied,
nothing owed, or — importantly — that it could not run at all and therefore
proves nothing. An older installation without the underlying command says
so plainly rather than appearing to have found no work. It never delays a
session starting, and can be switched off.
