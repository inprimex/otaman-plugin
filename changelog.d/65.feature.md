Agent instruction sets generated by `otaman init` now tell agents to
*write* shared knowledge, not only to read it.

Alongside the existing "check `.agents/knowledge/` for docs relevant to
your work", agents are now directed to record a durable fact the moment
it is paid for — an incident diagnosed, a constraint measured, a
cross-repo pattern ruled — each entry carrying the evidence that proves
it. There is deliberately no scheduled "update the knowledge base"
chore.

The instructions also gain a check-otaman-first guard: before building a
new mechanism for credentials, messaging, state, or scheduling, check
whether the platform already provides one and propose extending it
instead of building alongside it.

Two directories that were advertised to readers but never written to by
anything, `.agents/proposals/` and `.agents/decisions/`, are retired. A
ruling is now recorded as a decision entry in the knowledge surface, and
proposals live on the message bus where they were already being approved.
