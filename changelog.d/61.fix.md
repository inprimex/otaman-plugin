Task assignments are no longer sent out for a spec change that has not
been approved yet. Committing to the specs repository used to fan
assignments to every named agent as soon as a change folder was touched,
regardless of whether a human had approved it.

When a change is not ready, the dispatcher now says which change it
refused and why, instead of doing nothing quietly. Programs configured to
only warn still dispatch, and now report the warning rather than staying
silent.
