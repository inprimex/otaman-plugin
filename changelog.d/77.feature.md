`otaman doctor` now tells you when a release has been cut but not rolled
to your machine.

The runtime-freshness section gained a fourth subject: the installed
bundle. If a newer release exists, it is named alongside the one you have
and the remedy is to roll. If you are on the latest release it reports
healthy — even though the source repositories have moved on since, which
is simply how the release cadence works and is not a problem to fix.

Where the latest release cannot be determined — an ordinary install with
no deploy checkout to compare against — it says so rather than reporting
that everything is fine.
