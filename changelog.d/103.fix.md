A write by an agent whose identity cannot be established is now refused
rather than quietly permitted.

The guard that checks which agent may write where had no way to tell "asked
and found no identity" from "could not ask at all" — an installation too old
to answer the question looked the same as a genuinely unattributable write.
Refusing both would have blocked ordinary work on any installation running
behind the current release, which is the normal state of affairs, so it
permitted both.

The command it consults now reports those two cases distinctly, and only the
first is refused. The refusal applies to the single write, not the session,
and names both ways to resolve it.
