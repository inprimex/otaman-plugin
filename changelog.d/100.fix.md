Repositories that did not ask for the slow advisory security scan no longer
get one.

A change in how opting in is recorded reversed the meaning of the setting
the generator was reading, so the job was being added for every repository
that had declined it rather than the few that wanted it.

The tests could not have caught this: they only covered the case where
nobody had opted in, and both readings behave identically there. Both
directions are now covered.
