Critique cost records now distinguish a route run locally from the same model
run outside the tenant.

The key written for a route came from a stand-in that dropped that
distinction, so a local run would have been billed against the off-tenant
key. Those are different routes for cost and sensitivity purposes, and the
shared implementation that now supplies the key keeps them apart.

An installation whose core predates that key records no route rather than
falling back to the old form, since the old keys would collide with the new
ones once it catches up.
