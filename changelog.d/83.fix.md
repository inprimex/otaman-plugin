A halted-session report now names the task the agent was working on.

Knowing that an agent is stuck is only half of what a person needs;
knowing what it is stuck on tells them what they are about to interrupt.

Where the record names no task, the report says so and notes that such a
record may have been written by an older acknowledgement path rather
than declared by the agent — so the claim itself is worth checking. The
suggested remedy also mentions the other explanation for a frozen
record: a heartbeat that has stopped refreshing it.
