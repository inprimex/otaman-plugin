Otaman now tells you when a git hook is installed but cannot actually
run. Previously a hook whose dependencies were missing looked healthy at
install and in `otaman doctor`, while silently doing nothing — a real
deployment went weeks without task dispatch that way. Setup now fails
with the reason, and doctor reports it instead of showing OK.

Task dispatch also distinguishes outcomes that used to look alike. "No
otaman folder found" and "nothing to dispatch" are now separate, clearly
stated results, every run reports how many assignments it sent, and a
task labelled for a repository that cannot be resolved is reported as
dropped rather than quietly skipped.
