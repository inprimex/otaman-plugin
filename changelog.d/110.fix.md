Hooks now find an interpreter that can actually load the code they are about
to run.

The lookup knew only the layout of a development checkout, so on an
installed system it fell back to whatever plain Python was on the path and
handed callers an interpreter missing the very modules they needed. Anything
depending on it did nothing, quietly, on every deployed installation.

Each candidate is now tried by importing the module the caller names, rather
than merely checking that a file exists and is executable. If none can, the
lookup reports failure instead of returning something that will not work.
