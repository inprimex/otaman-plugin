Generated agent instructions now carry a knowledge index scoped to the
partitions that agent owns.

Programs can declare who owns each knowledge function under
`program.processes.knowledge`. An agent's instructions then list the
owners of every partition and preload the index lines for its own —
so the reading cost stays flat as the shared knowledge base grows,
instead of every agent carrying every entry.

Partitions nobody owns are listed as unowned rather than left out, and
an index trimmed to its line budget says how many entries it omitted.

The ownership hook now refuses an edit to a knowledge entry in a
partition owned by another agent, and names the owner to send it to.
Reading any partition stays open to everyone.
