A program that declares its post-commit observers as a list of mappings,
rather than a plain list of agent names, no longer produces unusable bus
messages.

The parser read nested lines as if they were observers, so trigger names
became recipients, and one of the resulting messages could not be read at all
because the recipient field held a value that is not valid in that position.
Such a block is now declined with an explanation, and nothing is sent. The
richer shape is not yet a declared part of the configuration format, so the
hook refuses it rather than interpreting it.

Recipient names that cannot appear in a filename are now cleaned for the
filename only; the recipient itself is left exactly as declared.
