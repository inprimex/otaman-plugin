The otaman folder now has a declared owner, and the generated per-agent
instructions say who it is.

Until now the repository every agent coordinates through was the only one
with no owner, so nobody was authorized to merge there. A prepared handover
waited a day for want of an answer to "who lands this", and went in as an
exception.

Ownership here means merge authority, not exclusive write access. Every agent
keeps writing the coordination surfaces — bus messages, status, blocked
entries, knowledge submissions — exactly as before.

Changes to the keys that define the fleet's structure are refused at commit
time, naming the key, including for the owner. Those keys decide which
repositories exist, who owns them, and who is notified of what, so the owner
merges them and the human authorizes them. Every other key commits normally,
and editing the file is unaffected.
