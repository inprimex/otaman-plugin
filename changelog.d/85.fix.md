A task whose completion is withdrawn is now re-assigned.

Dispatch skips tasks that have already been reported complete. If a
completion is later retracted — the checklist entry is un-ticked — the
old report kept suppressing the task, so it could never be re-assigned.

Un-ticking an entry now overrides an earlier completion report for that
task, and the re-assignment is named in the dispatch summary. An
ordinary edit to the checklist is not treated as a withdrawal, so work
that is genuinely finished still stays finished.
