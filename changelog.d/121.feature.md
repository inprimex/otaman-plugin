Critic selection for a proposal now resolves from configuration alone, and the
case where it cannot is reported precisely.

A proposal that touches only the repository its author owns — the most common
shape — previously resolved to no reviewer at all, because the author is
excluded from reviewing their own work and no configured policy could then
name anybody else. Declaring the roles table the platform now supports closes
that: an independent reviewer is selected without the dispatcher supplying
anything a configuration file cannot express.

Where a selection genuinely cannot be made, the reason distinguishes a policy
that ran and chose nobody from one that could not run because a declared input
was missing — and in the second case it names the missing input. The two had
been reported identically, which left a configuration error looking like an
answer.

The dispatcher supplies the critic role itself, so a correctly configured
program does not have to.
