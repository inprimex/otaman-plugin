The destructive-operation guard no longer stops an agent from merging a
pull request as part of work it was asked to do.

The guard asks for fresh confirmation before `gh pr merge`, which is
answerable only by someone present at that moment. An agent working on
its own had no way to answer, so the prompt became an indefinite stop
rather than a question — costing about eleven hours of delivery in a
single day.

It now asks only when the merge comes from a delegated sub-agent, which
is the situation it was written for. A merge from a session a person is
driving proceeds, because the instruction they just gave is the
confirmation. Every other guarded operation — force-pushing, pushing to
the main branch, deleting a repository or a shared branch — still asks
every time.
