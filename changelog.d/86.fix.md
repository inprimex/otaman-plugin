Sessions are no longer reported as stale just because a release was
installed.

Installing a release re-copies the plugin files, which updates their
timestamps even when the contents are unchanged. The freshness check
read those timestamps as "the configuration changed", so every running
session was reported stale the moment a release landed — sixteen of
sixteen, none of them genuinely out of date.

When the installed hook configuration matches the plugin repository's
byte for byte, its age is now taken from the commit that last changed
it. Sessions started before a real configuration change are still
reported, which is the case the check exists for.
