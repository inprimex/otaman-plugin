Checks verifying agreement with a neighbouring component now run in
continuous integration instead of quietly doing nothing.

Those checks read files from a repository the pipeline cannot fetch, so they
were skipped while the run still reported success. A change on the other
side went unnoticed by the gate and surfaced only when the suite was run by
hand.

The side of the agreement this component is responsible for is now recorded
here and checked on every run. Confirming the record still matches the
neighbour needs both repositories present, so it happens where they are —
a real limit, now stated rather than hidden behind a passing check.
