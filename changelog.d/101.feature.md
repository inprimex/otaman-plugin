The doctor now reports whether the installed agent harness matches the
version the project pinned.

A mismatch is reported as off-pin, with the fix named as a provisioning
step — never something to change while a session is running, since that
would alter the program currently executing the agent.

Where no version has been pinned, the result is reported as not checked
rather than as healthy, and names both the setting that would hold the pin
and the version actually installed. A fleet that was never compared must
not read as a fleet that matches. The same applies when a pinned harness
cannot be found or will not report its version.
