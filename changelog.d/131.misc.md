The rule deciding which configuration keys count as structural now lives in
one function, shared by the local commit guard and the server-side check that
backs it up.

The two had to agree exactly: a server check that classified changes
differently from the local guard would either permit what the guard refuses or
refuse what it permits, with each answer defensible from its own code. Sharing
the comparison removes that possibility rather than relying on the copies
being kept in step.
