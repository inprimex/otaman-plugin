The destructive-operation guard no longer interrupts commands that merely
mention a dangerous operation.

It matched the command text anywhere, so writing a commit message about
merging, grepping the guard's own source, or quoting `git push --force`
in a message all asked for confirmation as though the operation were
about to run. Reading about the guard tripped the guard.

It now matches only when a guarded command actually starts a command —
including after `&&`, a pipe, or inside a substitution, so a real
operation chained behind something else is still caught.
