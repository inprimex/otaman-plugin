Message parsing across Otaman now comes from a single shared
implementation. Reading a bus message, naming one, and clearing a blocked
task all behave identically whether you go through the CLI or an agent's
MCP tools, instead of each transport interpreting the format slightly
differently.

One visible effect: message timestamps display in a single consistent
format. Older messages that recorded the timezone as `+00:00` now show
the equivalent `Z`, matching everything written since.
