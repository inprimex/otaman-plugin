The session heartbeat now identifies its agent from the `.otaman`
marker, so an agent's status record keeps refreshing while their session
is alive.

It previously looked for the agent's name in `CLAUDE.md`, but `otaman
init` writes that line to the local, uncommitted instructions file
instead — so the lookup found nothing in any normal workspace and the
heartbeat worked only where a fallback environment variable happened to
be set.

Relatedly, when the heartbeat can find an otaman workspace but cannot
tell which agent it belongs to, it now says so instead of stopping
quietly. That silence was indistinguishable from the ordinary case of
running somewhere that isn't an otaman workspace at all.
