Generated agent instructions now record which generator wrote them, and the
doctor reports any that a different one did.

The record is written by the generator itself, in the same pass that writes
the instructions, so the two cannot describe different things — a stamp
applied afterwards would drift the moment the generator is run directly, as
provisioning does.

A file bearing no record is reported as not checked rather than out of date:
nothing is known about where it came from, which is not the same as knowing
it is old. Every instruction file on this installation is currently in that
state, and the report says so plainly instead of implying staleness it
cannot demonstrate.
