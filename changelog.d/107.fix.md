The bus cleanup tool now states that it can permanently delete messages.

Its description said it archived old messages and never mentioned loss. The
underlying operation archives and then, past a longer window, destroys —
both in a single run, so on a bus left unswept for months a message can be
archived and purged seconds apart. The preview option reports what would be
archived and never uses the word delete, so it reads as reassurance where
none is warranted.

That description is what an agent reads before deciding the call is safe,
which makes it the actual safeguard. It now says what the operation does,
records the incident that proved it, and notes that the tool is currently
non-functional here for unrelated reasons.
