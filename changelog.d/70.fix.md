The agent launcher now runs on macOS.

In tmux fleet mode it used a shell builtin that only exists in bash 4.0
and later. macOS still ships bash 3.2, so the launcher printed its
startup banner and then stopped with `mapfile: command not found` —
looking, briefly, as though it had started.

The same change makes the runner fallback work as documented: a missing
or incomplete runner endpoint file now falls back to launching tmux
sessions directly, instead of continuing with an empty endpoint and
failing later.
