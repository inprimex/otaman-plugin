A blocked task is no longer reported as ready to resume because some
unrelated specification changed.

The blocked list cross-references bus messages to say whether the change
an entry waits on has been approved and committed. The approval check
was scoped to the entry's own change; the committed check was not, so
any specification change anywhere marked every blocked entry resumable.

That is an instruction rather than a note — an agent is meant to resume
only once both signals arrive for its own change — so the report was
telling people to unblock work on evidence about something else.
