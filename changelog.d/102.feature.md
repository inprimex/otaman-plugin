The guards that read the coding agent's tool payloads now have a conformance
suite, run against a candidate agent version before a fleet upgrades to it.

Seven guards depend on the shape of those payloads without owning it, so an
upstream change could quietly stop one of them working. The most important
case is the signal distinguishing a delegated agent from the main session:
if it stopped arriving, the guard requiring fresh confirmation before a
delegated agent merges would silently stop asking.

The suite checks both directions — that a delegated action is still
challenged, and that an ordinary one still is not — because a guard that
challenges everything gets switched off and then protects nothing. It also
reports which agent version it tested, so a passing run cannot be mistaken
for a guarantee about some other version.
